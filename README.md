# Calculadora de Pavimento Flexível — DNIT

Dimensionamento de pavimento flexível pelo Método Empírico do CBR (DNIT IP-06/2004 · Manual de Pavimentação IPR-719), com verificação das inequações e memória de cálculo exportável em Word (.docx), PDF e Excel.

**Acesso:** https://igororcobras-hash.github.io/calculadora-dnit/

Funciona em qualquer navegador (Safari, Chrome, Edge, Firefox, Samsung Internet) no iPhone, Android e computador. O arquivo `index.html` também pode ser baixado e aberto diretamente no Android ou no computador.
